# MiniCompactRunes

Historically known as CompactRunes, this is a Midnight compatible port that just tracks runic power and runes in a simple display (debuffs can't be tracked by addons in Midnight, use the cooldown manager instead).

Useful to position near the center of your UI so you can view your runic power and rune cooldowns without having to move your eyes to the player frame. Also suits the theme of a flat/modern UI style.

This is a brand new addon and features will be added over time.

Feedback and feature requests are more than welcome!
